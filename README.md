# minna-budget-standards

政府機關、工協會所訂之經費編列基準及產業薪資基準之結構化資料庫，供撰寫政府計畫、獎補助案及企業計畫之「經費編列」時查用。

本 repo 公開。只收錄公開來源之基準值與出處，不收錄任何客戶資料或計畫內容。

## 1 收錄範圍

| 類別 | 例 | 資料夾 |
|---|---|---|
| 共通性基準 | 主計總處共同性費用、講座鐘點費、出席費及稿費、國內外出差旅費 | `standards/ey/` |
| 部會基準 | 經濟部、國科會、教育部、衛福部等之計畫經費編列基準 | `standards/<部會代號>/` |
| 計畫別規定 | SBIR、TIIP 等申請須知之會計科目及編列原則 | `standards/<部會代號>/` |
| 法定下限 | 最低工資、勞健保及勞退費率 | `standards/mol/` |
| 產業薪資 | 勞動部職類別薪資調查、工協會薪資調查 | `salary/` |

部會代號：`ey` 行政院（含主計總處、人事總處、國發會）、`moea` 經濟部、`nstc` 國科會、`moe` 教育部、`mohw` 衛福部、`mol` 勞動部、`pcc` 工程會。

## 2 資料格式

每一份基準文件一個 YAML 檔，格式見 `schema/standard.schema.md`。每筆資料都標明：

- 發布機關、文件名稱、發文字號、版本日期；
- 來源網址及來源類型（官方原文、學校或機關轉載、新聞）；
- 查證狀態：`確認`（已讀原文或可靠轉載之條文）、`推論`（由其他文件轉引或推算）、`待查證`。

## 3 使用方式

1. 編列經費時，先查 `standards/` 對應之計畫主管機關；
2. 計畫主管機關未訂者，依其指定之共通性基準（多為行政院或國科會）；
3. 引用時寫文件名稱與發文字號，不寫本 repo 之路徑；
4. 狀態非 `確認` 者，引用前先讀原文。
