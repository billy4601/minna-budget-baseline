# minna-budget-baseline

政府機關、工協會所訂之經費編列基準及產業薪資行情之結構化資料庫，供撰寫政府計畫、獎補助案及企業計畫之「經費編列」時查用。一律以最新版為準。

本 repo 公開。只收錄公開來源之基準值與出處，不收錄任何客戶資料或計畫內容。

## 1 資料夾分類

```
baselines/
  central/                中央機關
    dgbas/                行政院主計總處（出席費及稿費、共同性費用、出差旅費）
    dgpa/                 行政院人事行政總處（講座鐘點費）
    ndc/                  國家發展委員會（行政及政策類委託研究）
    pcc/                  公共工程委員會（資訊服務計費）
    mol/                  勞動部（最低工資、職類別薪資調查）
    nstc/ moe/ mohw/ moea/  各部會之計畫經費基準
  local/                  地方政府（例：kaohsiung/、changhua/ 之地方型 SBIR）
  private/                民間（例：cisa/ 中華民國資訊軟體協會）
tools/                    產生索引之程式
schema/                   資料格式
INDEX.md                  索引（程式產生）
BACKLOG.md                待收集
```

分類原則：

1. 依「發布者」分資料夾，不依費用項目或計畫類型分：一份基準同時涵蓋人事費、業務費、管理費，也同時適用多種計畫，只有發布者是唯一的；新版也是由發布者公布，依發布者分最容易追新版。
2. 依層級分 `central`／`local`／`private`：層級決定效力。編列時之適用順序為：計畫申請須知 ＞ 主管部會基準 ＞ 行政院共通性基準；民間資料只作市場行情佐證，不是基準。
3. 主計總處、人事總處、國發會分開，不併成「行政院」：三者各有主管法規系統，修正也各自發布。
4. 一份文件一個資料夾、一個版本一個檔案，檔名為生效日：查「某日適用哪一版」只要找不晚於該日之最後一個檔案；已公布未生效之新版（例：116 年起之出席費、最低工資）也能先收錄。
5. 依費用項目或計畫類型之查詢，由 `INDEX.md` 提供，不另建資料夾。
6. 解釋函、解釋彙編放在被解釋之基準資料夾下之 `interpretations/`，與該基準放在一起；`INDEX.md` 第 4 節列出全部解釋及其效力（現行、部分適用、停止適用）。
7. 條文全文以 Markdown 放在同版本 YAML 旁，可直接搜尋，並可用 git 比對新舊版差異；原始檔案（PDF 等）存放於 Google Drive，YAML 記錄其位置及雜湊值。

## 2 使用方式

1. 先看 `INDEX.md` 第 1 節之現行版，及第 2 節是否有已公布、未生效之新版（計畫執行期跨年時要用新版）；
2. 查費用項目時看 `INDEX.md` 第 3 節；有疑義時看第 4 節之解釋函；
3. 引用時寫文件名稱與發文字號，不寫本 repo 之路徑；
4. 狀態非 `確認` 者，引用前先讀原文。

更新索引：`python3 tools/build_index.py`。

### 4.2 接手時建議先做

依時效排序：

1. **更新已過時者**：每年 1 月前後，各計畫多會公告新年度之申請須知（推論，依往年慣例）。宜先查 116 年度版：地方型 SBIR（彰化、高雄）、SBIR 中央型及跨域型、教育部及衛福部補助基準；另查 116 年勞保、健保、勞退費率。
2. **收和申請案最相關者**：SBIR 中央型、TIIP、學界科專、法人科專、國科會專題研究之經費編列（見 `BACKLOG.md`「中央：部會」）。
3. **補齊共通性基準**：稿費支給基準數額表、大陸港澳出差日支數額、大專兼任教師鐘點費。
4. **待確認事項**：中華民國資訊軟體協會（CISA）與資訊軟體服務商業同業公會（TISSA）之關係；TISSA 報告是否可在本 repo 放全文（目前只摘錄數值）。
5. **全文校對**：全文初稿逐份校對，完成者 `fulltext` 改為 `已校對`。
